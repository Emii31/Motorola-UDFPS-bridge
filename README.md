# Motorola Native Local-HBM FOD Bridge (Magisk Module)

A high-performance Magisk module that implements native Local-HBM (Mode 4) optical fingerprint (FOD) support for Motorola devices running GSI / custom ROMs. 

- **No full-screen dimming scrims**
- **Hardware-level Local-HBM circle illumination**
- **Works instantly on screen-off and normal display**
